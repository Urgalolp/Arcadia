A computer is a powerful tool for information gathering and research. While anyone can use a computer to make Intelligence (Investigation) checks to discover information, those who are proficient with these tools can create programs, navigate complex network structures, and issue administrative commands while hiding their presence and covering their tracks. See "Using Electronic Devices" for more information regarding the use of computers.

Typically, desktop computers are more powerful than laptops, which are more powerful than tablets, which are more powerful than smartphones. Smartphone and tablet batteries usually last for about 24 hours, whereas laptop batteries typically last for roughly 8 hours.
